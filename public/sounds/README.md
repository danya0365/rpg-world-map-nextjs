# Sound Files for RPG World Map

This directory contains sound effects and music for the RPG World Map game.

## Required Sound Files

The following sound files need to be added to this directory:

### Battle Sounds
- `attack.mp3` - Player attack sound
- `defend.mp3` - Player defend sound
- `skill.mp3` - Player skill use sound
- `monster-attack.mp3` - Monster attack sound
- `critical-hit.mp3` - Critical hit sound
- `victory.mp3` - Battle victory sound
- `defeat.mp3` - Battle defeat sound
- `flee.mp3` - Flee from battle sound
- `item-use.mp3` - Item use sound
- `level-up.mp3` - Level up sound

### UI Sounds
- `click.mp3` - Button click sound
- `menu-open.mp3` - Menu opening sound
- `menu-close.mp3` - Menu closing sound

### Background Music
- `battle-music.mp3` - Battle background music
- `world-map-music.mp3` - World map background music

## Sound File Specifications

- Format: MP3
- Sample Rate: 44.1 kHz
- Bit Rate: 128-192 kbps
- Duration: 
  - Sound effects: 0.5-2 seconds
  - Background music: 1-3 minutes (loopable)
